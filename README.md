# yxss-data · 英雄史诗初章 数据资料库

> 2010 年 J2ME 手机游戏《英雄史诗初章》的**逆向解包资料站**。
> 纯静态站点，无后端、无框架，可直接部署到 GitHub Pages。

**⚠️ 本项目为非官方粉丝资料站，与游戏原作者、发行商无任何关系。**
所有数据由逆向分析游戏 jar 得出，仅供学习研究与怀旧查阅。

---

## 这是什么

《英雄史诗初章》是 2010 年的一款 J2ME 角色扮演游戏（240×320，CLDC 1.1 / MIDP 2.0）。

这个站点把游戏的内置数据解包出来，做成可查询的网页：

| 模块 | 内容 |
|---|---|
| **怪物** | 139 张地图的怪物分布、三档难度（普通/困难/地狱）的实际属性、等级区间 |
| **物品** | 591 条物品数据，含类别、等级、图标 |
| **地图** | 139 张地图的结构、怪物配置、NPC |
| **掉落** | 精确掉落概率（累计区间算法，非各概率独立） |
| **伤害计算器** | 按游戏真实公式计算伤害 |

## 数据从哪来

全部来自对原版 jar 的逆向分析：

- **字节码反汇编**逐方法确认算法（164 个类、1722 个方法）
- **数据文件解析**：`.tdf` 文本表、`.m` 地图脚本、`.mpm` 图集、`edf` 记录
- **真机实测验证**：关键数据在 Nokia N86 真机上逐项核对

> 例：掉落公式连续击杀统计验证，7/7 全部命中代码推导值。

## 技术栈

零依赖。原生 HTML + CSS + ES Module JavaScript。

```
web/
├── index.html              入口（骨架，内容全由 JS 渲染）
├── css/style.css           全部样式（设计令牌在文件开头）
├── js/
│   ├── core/               router / loader / ui / app
│   ├── config.js           ★ 站点配置 + 页面注册（扩展入口）
│   └── pages/              monster / map / calc
└── data/                   构建好的 JSON 数据
```

## 本地运行

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

> 需要 HTTP 服务器，因为用了 `fetch` 加载 JSON；直接双击 `index.html` 会被 `file://` 协议拦截。

## 部署

Settings → Pages → Source: `Deploy from a branch` → `main` / `/ (root)`。
全站使用相对路径，无需改配置。
